# riparian-avian-and-insect-monitoring

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22263232.svg)](https://doi.org/10.5281/zenodo.22263232)

This repository contains the reproducible methods and results presented in the research article:

> Jacuzzi, G., Pekich, S., Olden, J.D. 2026. Aquatic insect subsidies mediate current and future urbanization effects on insectivorous birds across spatial scales. Ecological Applications (in prep).

## Contents
- `data` – Data for acoustic monitoring and classifier configuration, avian species detections and traits, B-IBI surveys, environmental covariates and projections, and site metadata.
- `src` – All source code for data processing, covariate calculation, statistical analyses, model predictions, and figure generation. See documentation within each script for details.

Results can be reproduced in sequence with the manuscript beginning from script `src/4_msom.R`.
